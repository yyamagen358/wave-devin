【重要】バックエンドとフロントエンドの2つを起動する必要があります

┌─────────────────────────────────────┐
│ ステップ1: バックエンドを起動        │
└─────────────────────────────────────┘

1. PowerShellを開く（1つ目のターミナル）

2. 以下のコマンドを実行：

   cd "C:\Users\yyama\Documents\wave-devin\wave-poem-video-app\backend"
   poetry run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

3. 以下のメッセージが表示されればOK：

   INFO:     Uvicorn running on http://127.0.0.1:8000
   INFO:     Application startup complete.

4. このターミナルは閉じずに、起動したままにする


┌─────────────────────────────────────┐
│ ステップ2: フロントエンドを起動      │
└─────────────────────────────────────┘

1. 新しいPowerShellを開く（2つ目のターミナル）

2. 以下のコマンドを実行：

   cd "C:\Users\yyama\Documents\wave-devin\wave-poem-video-app\frontend"
   npm run dev

3. 以下のメッセージが表示されればOK：

   VITE v6.3.7  ready in xxx ms
   ➜  Local:   http://localhost:5173/

4. このターミナルも閉じずに、起動したままにする


┌─────────────────────────────────────┐
│ ステップ3: ブラウザでアクセス        │
└─────────────────────────────────────┘

1. ブラウザで以下のURLを開く：

   http://localhost:5173/

2. 「無条件の波動」のページが表示される

■ 4. 動画生成の使い方
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【方法1：直接ファイルを配置（推奨）】

素材を以下のフォルダに直接配置してください：

1. 詩ファイル（.txt）
   → C:\Users\yyama\Documents\wave-devin\wave-poem-video-app\backend\data\poem\

   ファイル名の例: 1480生まれたり死滅したり.txt

2. 背景画像（9:16縦型、1080x1920推奨）
   → C:\Users\yyama\Documents\wave-devin\wave-poem-video-app\backend\data\images\

   複数枚配置可能。ランダムに選択されます。

3. BGM（MP3形式）
   → C:\Users\yyama\Documents\wave-devin\wave-poem-video-app\backend\data\bgm\BGM.mp3

   ファイル名は必ず「BGM.mp3」にしてください。


【方法2：ブラウザからアップロード】

ブラウザの「ファイルアップロード」セクションから、
詩・画像・BGMをそれぞれアップロードすることもできます。


【動画生成】

1. ブラウザで http://localhost:5173/ を開く

2. 「詩の統計」で利用可能な詩の数を確認

3. 「単一生成」または「バッチ生成」のボタンをクリック

4. 青い進捗バーが表示され、生成状況が確認できます

5. 生成完了後、「生成済み動画」セクションからダウンロード

6. 生成された動画は以下にも保存されています：
   C:\Users\yyama\Documents\wave-devin\wave-poem-video-app\backend\data\videos\

【問題1】ブラウザで「接続できません」と表示される

原因: バックエンドまたはフロントエンドが起動していない

解決策:
  1. バックエンドのターミナルで以下が表示されているか確認：
     INFO: Application startup complete.
  
  2. フロントエンドのターミナルで以下が表示されているか確認：
     ➜  Local:   http://localhost:5173/


【問題2】「生成開始」ボタンがグレーでクリックできない

原因: バックエンドに接続できていない、または詩が0個

解決策:
  1. バックエンドが起動しているか確認
  2. ブラウザで http://localhost:8000/healthz にアクセス
     → {"status":"ok"} と表示されればOK
  3. 詩ファイルがpoemフォルダに入っているか確認


【問題3】動画生成が進まない（0%のまま）

原因: バックエンドでエラーが発生している

解決策:
  1. バックエンドのターミナルを確認
  2. [DEBUG] または [ERROR] メッセージを確認
  3. 素材（詩・画像・BGM）が正しく配置されているか確認


【問題4】ポート8000または5173が使用中

原因: 以前のプロセスが残っている

解決策:
  PowerShellで以下を実行：
  
  # Pythonプロセスを終了
  taskkill /F /IM python.exe
  
  # Node.jsプロセスを終了
  taskkill /F /IM node.exe
  
  その後、再度起動してください。

■ 7. 動画仕様
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 解像度: 1080x1920（9:16縦型）
- FPS: 24
- フォーマット: MP4 (H.264 + AAC)
- 構成:
  1. トップページ: 「無条件の波動」+ タイトル（3秒）
  2. 本文スライド: 2行ずつ表示（各3秒）
  3. ラストページ: 全文をロールアップ表示（文字数に応じて自動調整）
- BGM: フェードアウト処理あり

■ 8. 補足情報
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【詩のファイル形式】

ファイル名: 数字 + タイトル.txt（例: 1480生まれたり死滅したり.txt）
内容: プレーンテキスト（UTF-8）

例:
  無条件の波動
  ここから始まる
  言葉は映像へ
  心は波になる

【画像の推奨仕様】

- 解像度: 1080x1920（9:16縦型）
- フォーマット: JPG または PNG
- 複数枚配置可能（ランダムに選択されます）
- スライドごとに異なる画像が使用されます

【BGMについて】

- ファイル名: BGM.mp3（固定）
- フォーマット: MP3
- 動画の長さに合わせて自動的にフェードアウトします

【画像プール機能】

imagesフォルダに複数の画像を配置すると、スライドごとに
ランダムに選択されます。少数の画像でも多数の動画を生成できます。
