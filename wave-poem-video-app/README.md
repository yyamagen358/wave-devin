# 無条件の波動 - 詩の自動動画生成システム

詩のテキストファイルから自動的に動画を生成するWebアプリケーションです。

## 機能

- 詩のテキストファイルから自動動画生成
- トップページ：「無条件の波動」タイトル + 詩のタイトル表示
- 各段落を個別のスライドとして表示（1行11文字、中央配置）
- 最終ページ：全文をロールアップ表示（2行ごとに空行）
- 背景画像：9:16縦型のランダム選択・再利用
- BGM：フェードイン/アウト付き（3秒のスムーズなフェードアウト）
- 単一生成モード
- バッチ生成モード（複数動画を一度に生成）
- 動画ダウンロード機能
- **画像プールシステム：少数の画像で多数の動画を生成可能**

## セットアップ

### バックエンド

```bash
cd backend

# 依存関係のインストール
poetry install

# データディレクトリの準備
mkdir -p data/poem data/poem_used data/images data/bgm data/videos

# 詩ファイルを data/poem/ に配置
# 画像ファイル（9:16縦型）を data/images/ に配置
# BGMファイルを data/bgm/bgm_poem.mp3 として配置

# サーバー起動
poetry run fastapi dev app/main.py --port 8000
```

### フロントエンド

```bash
cd frontend

# 依存関係のインストール
npm install

# 環境変数の設定
echo "VITE_API_URL=http://localhost:8000" > .env

# サーバー起動
npm run dev
```

ブラウザで http://localhost:5173 にアクセス

## API エンドポイント

- `GET /api/poems/available` - 利用可能な詩の数を取得
- `POST /api/generate/single` - 単一動画生成
- `POST /api/generate/batch` - バッチ動画生成
- `GET /api/status/{task_id}` - 生成状況確認
- `GET /api/videos` - 生成済み動画一覧
- `GET /api/videos/{filename}` - 動画ダウンロード

## 使用方法

### Webインターフェース経由（推奨）

1. ブラウザでアプリケーションにアクセス
2. 詩ファイル（.txt）をアップロード
3. 背景画像（9:16縦型、.jpg/.png）をアップロード
4. BGMファイル（.mp3）をアップロード
5. 「生成開始」をクリック
6. 生成が完了したら動画をダウンロード

### 直接ファイル配置

1. 詩ファイル（.txt）を `backend/data/poem/` に配置
2. 画像ファイル（9:16縦型）を `backend/data/images/` に配置
3. BGMファイルを `backend/data/bgm/BGM.mp3` として配置
4. Webインターフェースで「生成開始」をクリック
5. 生成が完了したら動画をダウンロード

## 画像プールシステム（重要）

このアプリケーションは**画像再利用**システムを採用しています。

### 利点

- **大幅なアップロード削減**: 少数の画像で多数の動画を生成可能
- **効率的な運用**: 例えば7枚の画像で100個の動画を生成できます
- **一貫性**: 同じ画像セットを使うことで統一感のある動画シリーズを作成

### 仕組み

各動画生成時に、アップロードされた画像からランダムに選択します。
同じ画像が複数の動画で使用される可能性があります。

**例：10個の動画を生成する場合**

従来の方法：
- 詩ファイル: 10個
- 背景画像: 90枚（各動画に9枚 × 10）
- 合計: **100ファイル**

新しい方法（画像再利用）：
- 詩ファイル: 10個
- 背景画像: 20-30枚（プール）
- BGM: 1個（共通）
- 合計: **31-41ファイル（約60%削減）**

## 詩ファイルフォーマット

```
《タイトル1》

「タイトル2」

段落1の内容
複数行可能

段落2の内容
複数行可能
```

## 注意事項

- 動画生成には時間がかかります（1動画あたり約30-60秒）
- 使用済みの詩ファイルは自動的に `poem_used/` に移動されます
- 動画は `data/videos/` に保存されます
